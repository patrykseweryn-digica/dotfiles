# Obsidian Vault Folders

Use these folders for organization:

- **Firma/** - work: Digica company, business, sales, projects like Fortem
- **Inbox/** - quick, unsorted notes for later organization
- **Kuchnia/** - cooking, recipes, drinks
- **Nauka/** - science and learning
- **Osiąganie swoich celów/** - goals, habits, productivity
- **Osobiste/** - personal: health, contacts, jokes, sport, travel, dreams
- **Polityka/** - politics
- **Programowanie/** - programming: ML, Python, Front-End, DevOps, Git, architecture
- **Projekty/** - side projects
- **Wiara/** - faith, reflections, retreats
- **Zapiski & Notatki/** - writings: reflections/przemyślenia, books, essays

Daily Notes are off limits: never read, create, modify, move, summarize, or organize files in `Zapiski & Notatki/Daily Notes/`.

## Folder Choice

- If the note clearly fits an existing folder, use it.
- If unsure or it could fit multiple folders, ask the user.
- Quick, rough notes go to `Inbox/`.
- Polished, topic-specific notes go directly to the right folder.
- Never create new folders without explicit user approval.
