# Global Preferences

- Match my language (respond in the language I write in)
- Be concise; explain properly only when needed
- When stuck or unsure, ask immediately via AskUserQuestion
- Never commit or push unless I explicitly ask
- NEVER add Co-Authored-By, "generated by AI", or any other AI attribution to commits
- OS: Linux (Ubuntu) or macOS (Apple Silicon) — detect with `uname -s`
- Look up docs via Context7 when unsure about a library

## Tech Stack
- Python: `uv`, `ruff`, `pyright`, pre-commit hooks, `new-project <name>` (copier from `gh:p-severin/python-repo-template`)
- JS/TS: `eslint`, pre-commit hooks, React/Next.js/Express.js
- Always Docker: docker-compose for dev, multi-stage builds

## Workflow
- Before non-trivial tasks: read CLAUDE.md, explore code, prefer Plan Mode
- Plan Mode: extremely concise plans, sacrifice grammar for concision, list unresolved questions at end
- After plan approved: apply code changes immediately, don't describe them textually
- One logical change at a time - verify before next
- Git commit messages: short one-line summaries, no rigid format
- Before committing: run type checker (pyright/tsc), fix all errors
- Before applying a fix broadly, test on small sample first

## Code Quality
- Pragmatic: complete code, TODOs only for clearly out-of-scope items
- Pragmatic typing: proper types when easy, `@ts-ignore`/`type: ignore` OK for edge cases
- Handle only the most important/probable errors
- Write tests only when asked
- Secrets always via env vars, never hardcoded
- Feature-based organization (group by domain, not file type)
